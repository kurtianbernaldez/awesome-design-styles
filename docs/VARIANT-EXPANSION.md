# Three interpretations per family

The library now contains 114 complete design systems across 38 families. The initial nine variants remain; the other 35 families each gain two original interpretations. These names describe authored interface directions, not an exhaustive historical taxonomy.

The same semantic showcase is reused throughout. Family material construction is shared in CSS; each variant specifies its own organizing idea and overrides. Every DESIGN.md includes the full construction so it can be used independently.

## Validation

The build checks metadata, complete document sections, exact downloadable source, all direct routes, and semantic color-token contrast. The local browser audit checks desktop and narrow layouts, material rendering, modal and tab behavior, comparison state, and copy controls. Historical and material references remain in [the visual review](VISUAL-REVIEW.md).

Completed local review: 114 themes at 1100px, 390px, and 320px (342 viewport checks), all 38 family selectors, preserved iframe/form state, exact selected source, dialog and tab behavior, copy controls, and 114 refreshed preview images. Automated opaque-text sampling supplements the token checks; it is not a claim of complete accessibility certification.
